# Finite-level coefficient certificates

This package proves algebraic soundness lemmas for finite-level coefficient
certificates. It does not assert nonvanishing of an arithmetic theta element,
the nonzero localization research target, or BSD.

## Verified statements

For a prime `p`, set `omega_n(T) = (1 + T)^(p^n) - 1`.

- If `m + s <= n`, every positive-degree coefficient below `p^(s+1)`
  is divisible by `p^m`. The constant coefficient is exactly zero.
- For `0 < m <= n`, the coefficient at degree `p^(n-m+1)` has
  exact p-adic valuation `m-1`. Thus this truncation bound is sharp.
- If `F - G = omega_n * H + p^m * J`, where the series have coefficients
  in the same commutative ring, their coefficients below the certified
  cutoff agree modulo the principal ideal generated by `p^m`.
- If the coefficients of `F` below degree `d` vanish **exactly**, and the
  degree-`d` coefficient of `G` is not divisible by `p^m`, then `F` has
  exact order `d`.
- For quadratic order, `n >= m` suffices for primes `p >= 3`.
  At `p = 2`, the proved corollary requires `n >= m+1`.
- If `F(0)=0` exactly and
  `F(T)=U(T)F((1+T)^(-1)-1)` with `U(0)=1`, then `T^2` divides `F`,
  provided the coefficient ring has no additive two-torsion. This theorem
  uses actual formal-power-series substitution and the inverse of `1+T`.
  Its proof takes the linear coefficient, obtaining `F_1=-F_1`.

The final symmetry theorem is `X_sq_dvd_of_inversion_symmetry`. Its
conclusion supplies the exact-divisibility hypothesis of
`exact_order_two_of_certificate`; the theta functional equation and exact
zero constant term still require their arithmetic proofs. A sign with
`U(0)=-1` cannot be substituted for the stated plus sign.

The coefficient-ring generality includes the p-adic integers and integral
coefficient extensions. The multiplier `H` must be integral in that ring;
untracked denominators can reduce the precision. Nondivisibility by `p^m`
means a nonzero class modulo that ideal. No finite calculation substitutes
for the exact lower-order vanishing hypothesis.

The binomial valuation input is the existing Mathlib theorem
`Nat.factorization_choose_prime_pow_add_factorization`; these elementary
arithmetic facts are not claimed as new mathematics.

## Build and reproduce

The project pins Lean 4.36.0 and Mathlib commit
`fc4f59e577feb1a4956671bc04ac18aaaf8cd842` (Mathlib v4.36.0).
With the Lean toolchain available:

```sh
lake update
lake exe cache get Mathlib/Data/Nat/Choose/Factorization.lean Mathlib/RingTheory/PowerSeries/Order.lean Mathlib/Algebra/Polynomial/Coeff.lean Mathlib/RingTheory/PowerSeries/Substitution.lean Mathlib/RingTheory/PowerSeries/Inverse.lean
python3 verify.py
```

`verify.py` builds the actual Lean module, prints its theorem types and
axiom dependencies in a fresh Lean process, and replays the module through
`leanchecker` against its compiled imports. The receipt records source,
object, and log hashes. It does not claim an independent recheck of every
imported Mathlib object.

The source's fifteen theorems have no added axioms, unproved placeholders,
or native proof evaluation. The report allows only Lean's standard `propext`,
`Classical.choice`, and `Quot.sound` dependencies.

## Mathematical source

Castella and Hsieh, *On the nonvanishing of generalised Kato classes for
elliptic curves of rank 2*, Forum of Mathematics, Sigma 10 (2022), section 6,
uses finite-level theta elements modulo `((1+T)^(p^n)-1)` and truncation
modulo `(p^n,T^p)`. The generic coefficient lemmas here formalize that
certificate mechanism and a sharper precision/truncation bound.

https://doi.org/10.1017/fms.2021.85
